# Yoti PHP SDK examples

These examples are demo apps. Run them on your own computer only. Do not put them on a public server.

Always run them on a PHP version that still gets security updates (8.2.35, 8.3.36, 8.4.27, 8.5.12 or later). The Docker setup in `docker/php.dockerfile` uses a pinned PHP version.

See the README in each example for how to run it.
